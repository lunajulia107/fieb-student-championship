# Campeonato de alunos - FIEB

📁 Projeto fullstack para organizar e apresentar um campeonato de alunos, usando Node.js, Express, EJS, e banco de dados.

---

## Sobre o Projeto

📄 Aplicação web que permite registrar resultados de partidas entre alunos e exibir o pódio do campeonato. Backend em Node.js com Express, frontend com views em EJS, e arquivos estáticos no diretório público.

---

## Estrutura do Projeto

```
campeonatoDeAlunosFIEB/
│
├── app/
│   ├── public/            Arquivos estáticos (CSS, imagens, scripts)
│   ├── routes/
│   │   └── router.js      Definição das rotas da aplicação
│   └── views/
│       └── pages/         Templates EJS das páginas (index, campeonato, campeões)
├── .gitignore             Arquivos e pastas ignoradas pelo Git
├── app.js                 Arquivo principal do servidor
├── package.json           Gerenciador de pacotes NPM
├── README.md              Documentação do projeto
└── site.webmanifest       Manifesto do site (PWA, ícones)
```

---

## Tecnologias Utilizadas

💻

* Node.js
* Express
* EJS (Embedded JavaScript Templates)
* HTML, CSS e JavaScript para frontend

## Como Rodar o Projeto

▶️ Após clonar o repositório, execute os seguintes passos:

1. Instale as dependências:

```bash
npm install
```

2. Inicie o servidor com Nodemon ou Node:

```bash
npm run dev
# ou
node app.js
```

3. Acesse a aplicação no navegador:

```
http://localhost:9000/
```

> Obs.: Pode ser necessário atualizar a página algumas vezes devido ao carregamento da API e dados.
